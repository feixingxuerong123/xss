# dev/attic — 一次性探针与运行产物归档

2026-09-25 大扫除时从仓库根目录移入的内容。全部是 git 未跟踪的实验产物
(根目录 `_` 前缀 = 一次性草稿,是本项目的长期约定),移动未做任何修改。

## 内容

- `_p*.py` / `_q_*.py` / `_probe*.py` 等:各 Phase 的一次性探针脚本,
  与 `benchmark/` 里已固化的探针不同,这些只在当时跑过一次。
- `_rt*.json` / `_p176e_*.json` 等:上述探针的输出产物。
- `*.log`:分批测试、oracle、门禁的历史日志(结论已写进对应 Phase 的
  代码注释或报告,日志本身无回归价值)。
- `_diag*` / `_probe_out_*` / `_verify_*_out`:调试输出目录。
- `bak/`:代码 `.bak` 快照。git 即历史,这些快照已无作用,仅因
  "删除别人的文件前先问一句" 而保留在这里。

## 什么时候可以整个删掉

对应报告(全方面分析报告 / 实战验证交付报告)里引用的产物核对完毕、
结论都在 benchmark/results/ 有可复现记录之后,本目录可整体删除。
