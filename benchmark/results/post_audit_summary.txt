==================== Phase 93：async 变慢真因 ====================
  cProfile on neg-escape-03 (~23s):
    0.33s  扫描器自身 (_probe_param cumulative)
   22.9s  GetQueuedCompletionStatus  <- 进程在睡觉
  根因: AsyncScanner.jitter 默认 0.1，_throttle() 每请求固定睡 50-150ms
        （sync 的同名参数是限速间隔的比率，不开 --rate-limit 零开销）；
        cli_runner 两处构造都没传 -> 无开关可关。212 请求 ≈ 21s。
  修复: 默认 0.0 -> neg-escape-03 23.3s -> 0.47s；全矩阵 1525s -> 526s。

  排障路径（可复用）:
    1. TimedSession 分离请求内/外耗时 -> 98% 在请求之外
    2. 假 session（零网络）同代码 0.07s -> 排除 CPU
    3. 裸 aiohttp 100 请求 0.14s -> 排除传输层
    4. cProfile -> 0.33s 工作 / 22.9s I/O 等待 -> 锁定 _throttle 的 sleep
